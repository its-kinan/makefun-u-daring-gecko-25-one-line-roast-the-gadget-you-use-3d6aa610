One original one-line roast of the gadget I use every day: my earbuds auto-connect to my laptop the moment I walk past it and play my music to an empty room, like they're performing for the furniture. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
